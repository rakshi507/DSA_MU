Q7. why must data generally be sorted before applying binary search?
ans- Binary search works by repeatedly dividing the search range into halves. sorted data is required to determine whether to search the left or right half.

Q8. what is a singly linked list? how is it different from an array?
ans- A singly linked list is a collection of nodes where each node  contains data and a pointer to the next node. unlike an array,linked list elements are not stored in contiguous meomery and their size can grow dynamically.

Q9. what is a binary tree? what is the maximum number of children of a node?
